# PROJECT

## Project
Modern Music Player App

## Goal
Build a premium mobile-first music application for discovering,
playing, importing, organizing, and analyzing music.

## Platform
Mobile-first web application.

## Core Features
- Music discovery
- Search
- Favorites
- Playlists
- Music import
- Listening activity
- Full-screen music player
- Mini player
- Lock-screen player
- User profile

## Design Direction
Minimal, premium, editorial music UI.

Primary visual language:
- Off-white backgrounds
- Black typography
- Red accent
- Rounded cards
- Large album artwork
- Spacious layouts
- Minimal icons
