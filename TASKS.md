## Important Architectural Decisions
- **Strict Crosshair Lock-On & Gaze-Shooting Engine**: Replaced indiscriminate screen tapping with a strict gaze-and-shoot mechanic. The ray is cast exclusively through the center crosshair `(0, 0)`. Incoming cubes within $z \in [-18, 2.2]$ must align with the reticle (threshold 0.72) to trigger a green `LOCKED` state. Tapping while locked bursts the cube; tapping off-target triggers a recoil misfire without destroying off-screen cubes.
- **Quantized Musical Beat-Grid Synchronization**: Instead of arbitrary timer intervals, cubes spawn strictly on musical beat indices ($B = \text{floor}(\text{currentTime} / \text{beatDuration})$). Cube speed is dynamically calculated ($S = 36 / (\text{travelBeats} \times \text{beatDuration})$), guaranteeing that every cube arrives at the strike plane ($z = 0$) on an exact musical beat. Visuals (equalizer towers, crystal breathing, searchlights) pulse on an exponential decay beat phase.
- **Beat Burst 3D VR & Tap-to-Burst Engine**: Removed complex dual-lane saber slicing to eliminate phone control friction and tiny hitboxes. Introduced Raycaster tap-to-burst system with 1.35 unit proximity assist for intuitive phone touch and desktop click. Features 360° device gyroscope orientation mapping (`deviceorientation` + `screen.orientation.angle`), audio-reactive beat pulsing for cubes and arena lighting, dynamic Web Audio pop FX synthesizer, and crystal fragmentation particle physics.
- **Beat Saber VR Gyroscope & Dual Saber Control System**: Mathematically robust Three.js orientation pipeline combining W3C `deviceorientation` yaw/pitch/roll angles with `screen.orientation.angle` compensation for seamless portrait and landscape VR head tracking. Supports iOS 13+ permission elevation on user tap, instant view recentering, split-touch dual thumb slicing (Left half screen = Red Saber, Right half screen = Blue Saber), plus desktop PC fallback with mouse tracking and `A`/`D`/`Space`/Arrow keyboard slashing.
- **Three.js 3D Virtual Reality Architecture**: Immersive 360-degree WebGL engine with 3 dedicated environments: Stadium Concert Arena (The Weeknd / festival stage with truss rigs, giant audio-reactive LED video screen, 6 sweeping spot beams, and 180 animated bouncing crowd silhouettes waving light sticks), Lofi Night Mountain (starry galaxy sky, full moon, shooting stars, 3D campfire with glowing embers, pine trees, fireflies, and calm reflective lake), and Cyberpunk Rooftop. Supports touch/mouse 360 orbit look, iOS/Android device gyroscope motion sensors, split-screen stereo SBS mode for Google Cardboard / phone VR headsets, spatial ambient audio synthesizer (crowd murmurs & campfire crackles via Web Audio API), and quick access via NowPlayingModal, MiniPlayer, and NavigationDrawer.
- **Real YouTube Audio Stream Extraction Engine**: Python `yt-dlp` stream resolver in `/api/download/route.ts` fetching exact, high-fidelity audio streams directly from YouTube/Google servers for any song title or video ID, returning true audio binaries (`audio/mpeg`, `audio/mp4`, `audio/webm`).
- **Direct Phone & Device Storage Downloader**: `PlayerContext.tsx` `downloadTrack` function triggers browser DOM link downloads (`anchor.click()`), saving converted `.mp3`/`.m4a`/`.webm` files straight to the user's phone/computer download directory while caching in IndexedDB for offline app playback.
- **No-URL-Paste Song Downloader**: Redesigned `/import` page with instant song title/artist search bar, 1-tap **Download MP3** converter buttons on search cards and trending lists, plus optional URL accordion.
- **Offline Audio Engine & Auto-Healing**: High-fidelity 16-bit PCM RIFF stereo WAV audio generation fallback. Automatically detects and heals older corrupted blobs in IndexedDB during playback so user downloads never fail.
- **Playlist Song Picker Architecture**: Reusable `AddSongsModal` allowing users to search YouTube, pick from downloaded offline vault songs, or add from favorites/recommendations with live toggle states and instant feedback.
- **One-Time Onboarding Strategy**: First-time users enter their name/avatar once on `/login`. The session is cached in `localStorage` and synchronized with Convex `users` database table, bypassing the login screen on all subsequent visits.
- **Free-Tier & Hybrid YouTube Engine**: Official YouTube Data API v3 querying with automatic fallback to secondary search if unconfigured or quota-exceeded.
- **Offline Phone Storage Architecture**: High-capacity IndexedDB storage for downloaded song audio blobs and metadata + dual-engine audio player (`YouTubeAudioPlayer.tsx`) switching dynamically between online YouTube stream and local HTML5 audio blob.
- **Design Tokens**: Configured in `globals.css` per `.ai/DESIGN.md` (Off-white `#F8F9FA`, dark charcoal `#2D2D2D`, red accent `#D7192F`, black `#000000`).
- **Hardware & Lock Screen Integration**: Media Session API metadata, lock-screen position syncing, and persistent audio carrier for mobile background playback.
- **Navigation Drawer**: Persistent overlay menu supporting fast app routing, lock screen toggle, and profile access.
